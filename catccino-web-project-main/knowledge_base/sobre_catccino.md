"O Catccino é a primeira cafeteria temática de gatos da região. Nosso objetivo é proporcionar um ambiente acolhedor para os amantes de café e de felinos, além de ajudar na adoção de gatinhos resgatados. Nossa equipe é treinada para lidar com os animais e garantir o bem-estar deles. Não é permitido acordar os gatos que estão dormindo, nem dar comida humana para eles. O cliente pode interagir com os gatos, mas deve respeitar o espaço deles."
